# Personal-Portfolio

Personal Portfolio
Bu mening shaxsiy portfolio veb-saytim bo‘lib, unda o‘zim haqimdagi ma’lumotlar, texnik ko‘nikmalarim va aloqa ma’lumotlarim jamlangan.
Sayt bo‘limlari
🏠 Main (Asosiy sahifa)
Profil rasmi va qisqacha tanishtiruv
Frontend Developer sifatidagi maqsadlarim
Biladigan texnologiyalarim (HTML, CSS, JavaScript)
JavaScript yordamida yaratilgan mini Counter funksiyasi
👨‍💻 About (Men haqimda)
Shaxsiy ma’lumotlarim va qiziqishlarim
Texnik bilimlar darajasi progress barlar orqali ko‘rsatilgan
Belgilar sonini hisoblovchi mini funksiya
Frontend rivojlanish yo‘lidagi maqsadlarim
📞 Contact (Bog‘lanish)
Ism, email va xabar yuborish formasi
Instagram, Telegram va TikTok havolalari
Tashrif buyuruvchilar bilan bog‘lanish imkoniyati
Ishlatilgan texnologiyalar
HTML5
CSS3
JavaScript (DOM Manipulation)
Flexbox Layout
Responsive Design
Loyihaning maqsadi
Ushbu loyiha frontend dasturlash bo‘yicha o‘rganayotgan bilimlarimni amaliyotda qo‘llash va o‘z portfolio saytimni yaratish maqsadida ishlab chiqilgan. Sayt foydalanuvchilarga men haqimda ma’lumot olish va men bilan bog‘lanish imkoniyatini beradi.Habsidada organgan bilimlar boyicha birinchi katta loyiha
